# FitLog

## Short Description
FitLog is a dark, no-nonsense gym companion web application built with Next.js. It allows fitness enthusiasts to browse a comprehensive workout library, explore detailed exercise mechanics, curate a daily workout plan, and save favorite lifts for future sessions—all wrapped in a sleek, modern, high-performance UI.

## Technologies Used
* **Framework:** Next.js
* **Styling:** Tailwind CSS, DaisyUI
* **Icons & Typography:** FontAwesome, Google Fonts (Oswald, Inter)
* **State Management:** React Context API

## Key Features
1. **Curated Workout Library:** Browse a diverse collection of exercises categorized by muscle groups, equipment, and difficulty levels.
2. **Dynamic Daily Plan:** Easily add desired lifts to a personalized "Today's Plan" checklist and track your daily routine.
3. **Saved Favorites:** Bookmark exercises for quick reference and access them anytime in your saved list.
4. **Detailed Exercise Breakdown:** View in-depth information for every lift, including step-by-step instructions, equipment required, estimated calories burned, duration, and ratings.
5. **Fully Responsive Design:** Optimized for seamless performance and readability across mobile devices, tablets and desktops.
